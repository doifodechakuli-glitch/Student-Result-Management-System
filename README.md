# Student Result Management System

A Python-based Student Result Management System.

## Project Features

- Add Student Result
- Calculate Total, Percentage and Grade
- Check Pass/Fail Status
- Get Student Result using Roll No
- Show All Student Data
- Store Student Records in Excel

## Technologies Used

- Python
- OpenPyXL
- Excel
- Command Line Interface (CLI)
